# Test Set Format — RAGLab

## File Location
`data/testset.jsonl` — one JSON object per line. Generated by running `python src/merge_testset.py`.

Individual contributions go in `data/questions/<member>.jsonl` (e.g., `person1.jsonl`, `person2.jsonl`).

## Freeze Policy
**The test set is frozen at the start of Week 2.** No edits after freeze. Run `python src/validate_testset.py` before freezing.

---

## Field Specification

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string | ✅ | Unique ID. Format: `p<member>_q<nn>`, e.g. `p2_q01` |
| `source_member` | string | ✅ | Who wrote this question: `person1`, `person2`, `person3` |
| `question` | string | ✅ | The question as asked to the RAG system. Plain English. |
| `reference_answer` | string | ✅ | Full reference answer. Used by judge for correctness scoring. |
| `gold_evidence` | object | ✅ | See sub-fields below |
| `gold_evidence.source` | string | ✅ | Which corpus source: `"fastapi"` or `"pytorch"` |
| `gold_evidence.section` | string or null | ✅ | Section heading in the processed document. `null` for unanswerables. |
| `gold_evidence.span` | string or null | ✅ | **Exact verbatim text** from the corpus passage that answers the question. `null` for unanswerables. |
| `answerable` | boolean | ✅ | `true` if the answer is in the corpus. `false` if the system should refuse. |
| `type` | string | ✅ | One of: `"factual"`, `"procedural"`, `"conceptual"`, `"unanswerable"` |

---

## Gold Span Rules (IMPORTANT)

- The `gold_evidence.span` **must be exact verbatim text** copied from the corpus — character-for-character match with the processed text in `data/processed/`.
- Run `python src/validate_testset.py` to verify every span exists in the corpus.
- For unanswerable questions: set `"answerable": false`, `"section": null`, `"span": null`.

---

## Question Mix Guidelines

Each person should write approximately:
- 5–6 **factual** questions (direct lookup: what is X, what does Y parameter do)
- 2–3 **procedural** questions (how-to: step-by-step tasks)
- 1–2 **conceptual** questions (why/how does X work, difference between X and Y)
- 1–2 **unanswerable** questions (asks about something not in the corpus)

Total target: **10 questions per person** (30 total — the 3-week fallback plan minimum, which is acceptable per blueprint).

---

## Example Entry

```json
{
  "id": "p2_q01",
  "source_member": "person2",
  "question": "What is the purpose of the `response_model` parameter in a FastAPI path operation decorator?",
  "reference_answer": "The `response_model` parameter tells FastAPI what data shape to use for the response...",
  "gold_evidence": {
    "source": "fastapi",
    "section": "Response Model - Return Type",
    "span": "You can declare the type used for the response by annotating the path operation function return type."
  },
  "answerable": true,
  "type": "factual"
}
```

---

## Validation Script

`python src/validate_testset.py` checks:
1. Every required field is present
2. Every `span` (for answerable questions) is found verbatim in the processed corpus
3. All `id` values are unique
4. `type` is one of the four allowed values
